# Amazon Products Sales Analysis Dashboard

An interactive *Power BI Sales Analysis Dashboard* built to analyze Amazon product sales performance, product categories, customer reviews, and sales trends.

## 📊 Key Metrics

- *YTD Sales:* $2.18M
- *QTD Sales:* $811.09K
- *YTD Products Sold:* 27.75K
- *YTD Reviews:* 19.42M

## 🎯 Project Objective

The objective of this project is to transform Amazon product sales data into an interactive dashboard that provides insights into sales trends, category performance, product performance, and customer review activity.
